---
title: Embeddings
description: POST /v1/embeddings, string input and float or base64 vectors, on OpenAI, OpenRouter and self-hosted routes.
---

```http
POST /v1/embeddings
```

```json
{"model": "example/embed", "input": ["First document", "Second document"], "encoding_format": "float"}
```

## Request fields

| Field | Supported |
|---|---|
| `model` | Required. |
| `input` | A non-empty string or list of strings. Token-id arrays are refused. |
| `encoding_format` | `float` (also when absent or `null`) or, from v0.7.1, `base64`: each vector as standard padded base64 of little-endian 32-bit floats. The OpenAI SDKs ask for `base64` by default and decode it for you. |
| `dimensions` | Only where the route's profile supports it (below). |

Not streamed. Up to 128 inputs and 1 MiB of text in total; `dimensions` up to 16,384. From v0.10.0 a request body streamed past the size limit gets the OpenAI `payload_too_large` error. [Batch](/docs/api/batches) embedding lines are float only and refuse `base64`.

## Response

The OpenAI list shape, with one finite vector per input, all the same length, in input order, as floats or base64. `usage` holds the input tokens when the provider reported them, and is left out otherwise. The provider is always asked for floats; the encoding is applied by the gateway. Vectors and the response size are checked before the request is settled, so an invalid upstream answer fails the request without being charged as a success.

## Providers

| Connection | Notes |
|---|---|
| OpenAI | Native; `dimensions` supported. |
| OpenRouter | Float vectors; `dimensions` only equal to the model's fixed native width, where it has one. |
| vLLM, SGLang | OpenAI-style; bounded `dimensions`, subject to the model. |
| OpenAI-compatible | OpenAI-style; no `dimensions`. |
| Ollama | Native `/api/embed` on the approved address, with truncation off; no `dimensions`. |

## Cost

Embeddings are input-only: the gateway holds the route's full input ceiling and no output. Set the input ceiling to the model's real limit, on a server that doesn't silently truncate long input: the gateway trusts the configured ceiling and can't measure it.
