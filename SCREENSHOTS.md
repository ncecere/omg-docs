# Screenshot capture list

Every image in these docs has a named slot in `lib/screenshot-slots.json` (its alt text and the file names it may have) and is placed with `<Screenshot slot="…" />`. Until an image is imported, the page shows a marked placeholder. This file is the capture list for the screenshot session. **No screenshots have been captured yet.**

## Rules

- **Only the fictional demo instance, never a real install.** Institution: **Example University**, domain `example.edu`, installation name "Example University AI Gateway". Never show a real person, organisation, key, address or provider account.
- **Generic model names.** Gateway model names `example/chat`, `example/chat-fast`, `example/assistant`, `example/embed`, `example/image`, `example/transcribe`, `example/voice`, `example/rerank`; display names such as "Chat model", "Fast chat model", "Embeddings model". Use generic upstream model ids on the self-hosted connection (`chat-small`, `chat-large`, `embed-small`), and avoid showing real provider model ids where a page allows it.
- **No paid requests.** Seed activity through a mock upstream on the approved self-hosted endpoint, as the project's browser test suite does. Cloud connections can exist and be disabled; their credentials are `env:` references only.
- **Personas** (all fictional):
  - **Morgan Lee**, `morgan.lee@example.edu`, Platform Admin
  - **Taylor Brooks**, `taylor.brooks@example.edu`, Platform Auditor
  - **Priya Shah**, `priya.shah@example.edu`, Platform User; owner of the Team **Chemistry Teaching** and admin of the Project **Climate Data Study**
  - **Sam Ortiz**, `sam.ortiz@example.edu`, Platform User; member of Chemistry Teaching and Climate Data Study
  - **Jordan Kim**, `jordan.kim@example.edu`, signs in with no platform role (denied)
- **Configuration**: connections "University GPU cluster" (vLLM, `http://models.example.internal:8000/v1`, approved in `GATEWAY_LOCAL_UPSTREAMS`), OpenAI, Anthropic, Amazon Bedrock (`eu-west-1`), OpenRouter. Catalogs "Self-hosted", "Approved cloud", "Advanced cloud". Cost centers `CHEM` (Chemistry) and `GEOS` (Geosciences). SSO groups `ai-gateway-users`, `ai-gateway-audit`, `ai-gateway-admins`, `chem-teaching-staff`. File store on MinIO.
- **Size**: PNG, **1440×900** (device scale factor 1), light theme unless the state says otherwise. Phone slots: **390×844** CSS pixels (scale 3 is fine; the import script keeps width ≤ 1600 px).
- **Version**: Open Model Gateway **v0.3.0** (main until tagged). Pin the clock in the seed so timestamps don't churn.
- **Secrets**: any key shown once must be replaced with a fake value (`omg_0000…`) before capture.
- **File name**: the slot name, `<slot>.png`, in the screenshots directory (`../omg-assets/screenshots` by default), then:

  ```sh
  SCREENSHOTS_DIR=../omg-assets/screenshots npm run screenshots
  npm run screenshots:check
  ```

- After replacing an image, check its slot's alt text in `lib/screenshot-slots.json` still describes it.
- A slot with `"hold"` in the slots file is skipped by the import; none is held now.
